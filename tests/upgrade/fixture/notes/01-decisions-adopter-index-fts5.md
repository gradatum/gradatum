Le magasin de notes retient un index FTS5 unique, derivable depuis les fichiers markdown.
Le jeton **zenith** sert de marqueur de verification dans ce corpus.

Motif : la recherche lexicale doit rester reconstructible hors ligne, sans service externe.
Consequence assumee : une reconstruction d'index est un cout borne et rejouable.
